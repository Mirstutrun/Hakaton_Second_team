# Геометрический аудит RoadForge

Инструмент **«Топология»** проверяет геометрию локального OSM-файла без изменения исходных данных.

## Категории

- **Пересечения без общего узла**: геометрическое пересечение двух дорожных сегментов на одном уровне, но без общего OSM node ID. Мосты, тоннели, крытые и внутренние дороги исключены из подсказки на соединение.
- **Дорога через здание**: центральная линия проезжей части пересекает замкнутый контур здания. Не является доказательством ошибки: нужна визуальная проверка, например, на Яндекс Картах. Не учитываются здания из multipolygon relations и сложная высотная геометрия.
- **Конец рядом с другой дорогой**: свободная конечная вершина way расположена ближе 3,5 м к другой дорожной линии. Может быть корректным подъездом, тупиком или разницей в высоте.
- **Почти нулевой сегмент**: последовательные узлы ближе 0,2 м.

Проверка основана на локальной метрической проекции и spatial hash (ячейки 70 м). Показывает максимум 300 предупреждений для сохранения отзывчивости интерфейса.

## Как исправить обнаруженное пересечение

1. Включить «Топология», выбрать строку и найти место на сцене.
2. Проверить, что дороги действительно соединяются на земле; не являются мостом/тоннелем, съездом или развязкой.
3. Только для пересечений **внутри двух сегментов** доступна кнопка «Соединить узлом». После подтверждения создаётся один OSM node, который вставляется в оба way. Изменение записывается как одна команда Undo/Redo.
4. Экспортировать файл OSM и перепроверить результат на сервере организаторов.

Концы сегментов не объединяются автоматически: там могут быть отношения, светофоры и узлы со своими тегами. Совмещение узлов нужно делать осознанно через инструмент редактирования.

## Карта-эталон

В панели сравнения встроена справочная карта Яндекса с центром у выбранного объекта. Это **не геодезически синхронизированная подложка**: масштаб, поворот и положение 3D-камеры не синхронизируются с iframe. Доступность iframe и законность использования картографических данных зависят от правил провайдера. Для точного наложения необходим официальный картографический API и отдельная реализация преобразования координат / тайлов.

## Не покрыто

- Маршрутизация с учётом всех ограничений движения и односторонних участков.
- Построение и проверка целого дорожного графа с береговыми обрывами, связностью мультиполигонов и реальной высотой зданий.
- Автоматическое перемещение дорог «из зданий» или автоматическое совмещение по снимкам.
- Проверка пригодности для MATSim / SUMO / Webots: только на сервере организаторов.

Любая геометрическая правка требует финальной визуальной проверки с достоверной подложкой.
