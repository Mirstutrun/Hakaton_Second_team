Добавлено рабочее приложение Vue 3 + Pinia + Babylon.js поверх OSM-ядра. Пользователь открывает карту, переключает 3D/2D, выбирает дороги, меняет полосы и направления, рисует новые ways с привязкой к общим узлам, вставляет и перемещает вершины, создаёт и редактирует светофоры. Экспорт записывает изменения в OSM; работают Undo/Redo и защита несохранённых правок.

Сцена строится из реальной карты: дорожные полотна и разметка, пешеходные пути, здания, светофоры. Правки обновляют затронутые meshes без пересоздания Engine/Scene. Добавлены интерфейс инспектора, поиск по ID, слои, горячие клавиши и документация для следующих участников.

Проверки: `npm run build`, 11 тестов ядра, Playwright-сценарий на полном `example.osm`. В браузере подтверждены расширение дорожного mesh до 13.6 м при 2→4 полосах, рисование, перенос вершины на 50 м, установка и атрибуты светофора, удаление/Undo/Redo, экспорт и повторный импорт с сохранением правок.

Этот PR зависит от `feat/foundation-core`. После объединения первого PR переключите базу этого PR на общую основную ветку. `docs/HANDOFF.md` содержит контракты, результаты и ограничения. Split-way, multipolygon-здания, сложные перекрёстки и серверные MATSim/SUMO/Webots-прогоны остаются следующими задачами; допуск к хакатону не заявляется. Сборка предупреждает о размере Babylon bundle.
