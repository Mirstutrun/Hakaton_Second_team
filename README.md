# RoadForge 3D

Мы сделали редактор дорожной сети для хакатона «Редактор карт». В нём можно открыть карту OpenStreetMap, посмотреть её в 2D или 3D, создать дорогу, переместить её точки и изменить количество и направления полос. Чтобы вручную соединить выбранную дорогу или полосу с другой дорогой, нужно нажать J и указать вторую дорогу на карте.

В разделе «Транспорт» можно добавить машины, поставить автобусные остановки с нужной стороны дороги и собрать маршрут автобуса. Это простой предпросмотр движения. Машины исчезают в конце пути. Кнопка «Проверка» показывает проблемы сети и доступные исправления. Изменённую карту можно сохранить в OSM, а случайное действие отменить через Ctrl+Z.

Здания показываются только как ориентиры. Создавать, удалять и редактировать их нельзя. Инструментов для светофоров нет, но исходные данные карты сохраняются при экспорте.

## Запуск через Visual Studio Code

Установите Node.js 22 или новее и Visual Studio Code. Скачайте ветку `2dayresults`, распакуйте архив и откройте папку проекта через «Файл → Открыть папку». В этой папке должен находиться `package.json`.

Откройте в VS Code меню «Терминал → Создать терминал». В Windows выполните:

```powershell
npm.cmd ci
npm.cmd run dev
```

В Linux и macOS используйте те же команды с `npm` вместо `npm.cmd`. После запуска перейдите по адресу из строки `Local` в терминале. Обычно это `http://localhost:5173`. Пример карты Иркутска загрузится автоматически. Терминал нужно оставить открытым, для остановки нажать Ctrl+C. Открывать `index.html` двойным кликом или через Live Server не нужно.

Чтобы собрать версию для размещения на сайте и проверить её локально:

```powershell
npm.cmd run build
npm.cmd run preview
```

Готовые файлы будут в папке `dist`. Её содержимое можно разместить на статическом хостинге. Тесты запускаются командой `npm.cmd run test`.

## Технологии

Интерфейс написан на Vue 3 и TypeScript. Babylon.js строит объёмную карту и обрабатывает выбор объектов мышью. Pinia хранит состояние редактора и историю действий, Vite запускает проект и собирает готовую версию. Для оформления используем CSS, для проверок Vitest и Playwright. Сервер и база данных для работы редактора не нужны.
