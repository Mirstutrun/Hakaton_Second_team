# Редактор транспортной карты (2D и 3D)

> Веб-приложение для редактирования дорожной сети OpenStreetMap в 2D и 3D с возможностью проверки графа и экспорта изменений в формат OSM.

## Функциональные возможности

### 1. Работа с дорожной сетью

- Загрузка и отображение карт OpenStreetMap
- Просмотр дорожной сети в режимах **2D и 3D**
- Создание новых дорог и изменение существующих
- Редактирование геометрии дорог и положения узлов
- Изменение количества полос и направлений движения
- Ручное соединение дорог и отдельных полос с помощью `J`
- Создание моста клавишей `G`: выберите подходы, нарисуйте пролёт и нажмите Enter. Мост и дорога под ним пересекаются на разных уровнях.
- Установка светофора клавишей `T` и кликом по дороге. В свойствах можно задать секунды красного и зелёного. В режиме «Транспорт» машины ждут на красный и продолжают движение на зелёный.
- Сохранение изменений в формате `.osm`

### 2. Моделирование движения

В редакторе предусмотрен раздел **«Транспорт»**, позволяющий проверить движение по созданной дорожной сети. Реализованы следующие возможности:
- Добавление автомобилей на карту
- Визуализация движения транспорта по дорогам
- Размещение автобусных остановок с выбранной стороны дороги
- Создание автобусных маршрутов
- Предварительный просмотр движения автомобилей и автобусов

Движение транспорта представляет собой упрощённый локальный предпросмотр. Автомобили исчезают после завершения пути.

### 3. Проверка дорожной сети

Раздел **«Проверка»** предназначен для поиска потенциальных ошибок в дорожном графе.

Возможности:

- Выявление проблем геометрии и связности дорожной сети
- Визуальное отображение обнаруженных проблем
- Просмотр доступных способов исправления
- Ручная корректировка проблемных участков

Проверка помогает обнаружить ошибки перед экспортом, также можно **сверить участки с Яндекс.Картами** в реальном просмотре (во время редактирования).

### 4. Импорт и экспорт данных

Редактор работает с файлами формата **OpenStreetMap (.osm)**. Изменения геометрии и дорожных атрибутов записываются обратно в OSM. Полученный файл предназначен для дальнейшей проверки в транспортных симуляторах.

## Как работает редактор? Сценарий использования

1. **Загрузка карты.** Пользователь открывает файл `.osm`. По умолчанию загружается пример дорожной сети Иркутска.
2. **Редактирование.** В режиме 2D или 3D пользователь изменяет геометрию дорог, полосы и другие доступные параметры.
3. **Проверка.** Редактор отображает найденные проблемы графа, которые можно изучить и исправить (раздел "Проверка")
4. **Предпросмотр движения.** Пользователь может добавить транспорт и проверить его поведение на изменённой сети.
5. **Сохранение результата.** Отредактированная карта экспортируется в файл `.osm`.

## Используемые технологии

| Технология | Назначение |
|---|---|
| **Vue 3** | Разработка пользовательского интерфейса |
| **TypeScript** | Логика приложения и типизация данных |
| **Babylon.js** | Визуализация дорожной сети в 2D/3D и взаимодействие с объектами |
| **Pinia** | Управление состоянием редактора и историей изменений |
| **Vite** | Локальный запуск и сборка приложения |
| **CSS** | Оформление интерфейса |
| **Vitest** | Модульное тестирование |
| **Playwright** | Автоматизированное тестирование в браузере |

Приложение работает локально в браузере и **не требует отдельного сервера, базы данных или регистрации пользователя**.

## Запуск через Visual Studio Code

Установите Node.js 22 или новее и Visual Studio Code. Скачайте ветку `3days`, распакуйте архив и откройте папку проекта через «Файл → Открыть папку». В этой папке должен находиться `package.json`.

Откройте в VS Code меню «Терминал → Создать терминал». В Windows выполните:

```powershell
npm.cmd ci
npm.cmd run dev
```

В Linux и macOS используйте те же команды с `npm` вместо `npm.cmd`. После запуска перейдите по адресу из строки `Local` в терминале. Обычно это `http://localhost:5173`. Пример карты Иркутска загрузится автоматически. Терминал нужно оставить открытым, для остановки нажать Ctrl+C. Открывать `index.html` двойным кликом или через Live Server не нужно.

Чтобы собрать версию для размещения на сайте и проверить её локально:

```powershell
npm.cmd run build
npm.cmd run preview
```

Готовые файлы будут в папке `dist`. Её содержимое можно разместить на статическом хостинге. Тесты запускаются командой `npm.cmd run test`.
