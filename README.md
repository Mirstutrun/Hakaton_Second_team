# RoadForge 3D

Локальный 3D/2D-редактор дорожной сети OpenStreetMap. Vue 3 + TypeScript + Vite + Pinia + Babylon.js. Карта и правки остаются в браузере; сервер, регистрация и API-ключи не нужны.

## Запуск

Нужен Node.js 22+; проверено на Node.js 24.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Пример Иркутска загрузится автоматически. «Импорт» открывает другой `.osm`. `npm install` также поддерживается; для воспроизводимой установки предпочтителен `npm ci`.

```bash
npm run test
npm run build
npm run preview
```

Браузерный сценарий:

```bash
npx playwright install chromium
npm run test:e2e
```

Тест использует системный Chromium, если он есть в `/usr/bin/chromium`, иначе браузер Playwright. Другой исполняемый файл задаётся через `CHROMIUM_PATH`. Для Linux при отсутствии системных библиотек используйте официальный `npx playwright install --with-deps chromium`. В облачной среде с недоступным домашним npm-кешем: `npm ci --cache /workspace/.npm-cache`.

## Редактирование

- **V — выбор:** нажмите на дорогу или светофор; свойства появятся справа. Можно искать `way/ID`, `node/ID` или числовой ID.
- **D — дорога:** кликайте по карте. В пределах 8 м от существующего наземного дорожного узла используется его ID. Enter завершает дорогу, Escape отменяет черновик.
- **M — геометрия:** выберите дорогу, затем перетащите её маркер. Общий узел изменится во всех связанных ways.
- **I — вершина:** клик по сегменту вставляет узел. Удаление выбранной вершины доступно в инспекторе; общие и значимые узлы защищены.
- **T — светофор:** клик по дороге добавляет светофор на ближайшем сегменте. Его направление редактируется справа; перенос — инструментом геометрии. Удаление убирает теги светофора и оставляет дорожный узел.
- **F — центрирование**, **Ctrl/Cmd+Z — Undo**, **Ctrl/Cmd+Shift+Z — Redo**, **Ctrl/Cmd+S — экспорт**.
- Кнопки **3D / 2D** переключают орбитальный и точный ортографический виды. Колесо — масштаб; правая кнопка — панорама; левая — вращение в 3D.

Поля справа редактируют весь way. Изменение `lanes` меняет ширину и разметку, если у дороги нет явного `width`; его приоритет указан в панели. Визуальные значения по умолчанию не добавляются в OSM.

Удаление дороги требует подтверждения. Дороги, участвующие в relations, защищены от удаления. Общие и неиспользуемые узлы автоматически не удаляются.

Экспорт скачивает `имя-edited.osm`. Для сдачи переименуйте файл в название команды по инструкции организаторов. Перед закрытием вкладки экспортируйте изменения: история и правки хранятся в памяти браузера.

## Полосы и локальный трафик

- Запуск по умолчанию в **2D** (кнопка **3D** переключает вид).
- Выберите дорогу и нажмите на отдельную полосу либо выберите её номер в инспекторе. Подсветка показывает выбранную полосу. Можно задать `turn:lanes`, `change:lanes`, `maxspeed:lanes` и направление движения через стандартные OSM-теги. Эти изменения сохраняются в `.osm`.
- Визуальные повороты сглаживаются Bézier-кривыми с сохранением общих перекрёстков. Это отображение не меняет OSM.
- В инспекторе есть отдельная команда **«Скруглить повороты (OSM)»**: вставляет новые OSM-узлы на кривых и записывает результат в экспорт. Общие перекрёстки, светофоры и узлы с тегами не затрагиваются. Можно отменить Ctrl+Z.
- В панели **«Машины»** добавляйте автомобили на выбранную дорогу (+1/+10) или по всей карте (если ничего не выделено), ставьте на паузу, регулируйте скорость, выбирайте автомобиль кликом и удаляйте его. Машины движутся по узлам сети, учитывают `oneway`, базовое `maxspeed`, светофоры и дистанцию до следующей машины. Это локальный приблизительный предпросмотр, **не SUMO/MATSim**; машины не экспортируются в OSM.

### Клавиши

| Комбинация | Действие |
|---|---|
| V / D / M / I / T | Выбор / новая дорога / перенос / вставка вершины / светофор |
| Ctrl/Cmd+Z | Отмена |
| Ctrl/Cmd+Shift+Z, Ctrl/Cmd+Y | Повтор |
| Ctrl/Cmd+S | Экспорт OSM |
| Ctrl/Cmd+O | Импорт OSM |
| C / Shift+C | Добавить 1 / 10 автомобилей |
| Space | Пауза / пуск движения |
| Delete | Удалить выбранный автомобиль |
| F | Центрировать выбранный объект |
| Enter / Escape | Завершить / отменить рисование дороги |

### Windows и ошибка Babylon.js gpuPicker.js.map

Обновите ветку и выполните `npm ci`, затем `npm run dev`. Перед запуском автоматически проверяется повреждённая исходная карта `node_modules/@babylonjs/core/Collisions/gpuPicker.js.map`, которая при некоторых неполных npm-установках вызывает `Unterminated string literal`. Повреждённая карта отладки удаляется, код Babylon.js не изменяется. При сохранении ошибки очистите оптимизационный кеш `node_modules/.vite` и перезапустите с `npm run dev -- --force`.

## Геометрический аудит и сравнение с картой

- **«Топология»** показывает на карте предупреждения об ошибках пересечений, пересечении дорожной оси со зданием, разорванных связях и почти нулевых сегментах.
- Для пересечений двух дорог на одном уровне внутри их сегментов доступна **ручная операция «Соединить узлом»** с подтверждением и поддержкой Undo/Redo. Мосты/тоннели не соединяются автоматически.
- **«Карта-эталон»** открывает отдельную панель Яндекс Карт в районе выбранного объекта. Это справочная карта **без точной синхронизации слоёв и масштаба**, а не геопривязанная подложка. Доступность зависит от провайдера.
- Инспектор содержит расширенные параметры дорог и **редактор произвольных OSM-тегов**.
- Все проверки только диагностические: дороги через здания не передвигаются автоматически. Для реальных исправлений нужны ортофотоплан/снимки и проверка человеком.

Документация ограничений и алгоритмов: [Геометрический аудит](docs/GEOMETRY_QA.md).

### Docker

```bash
docker build -t roadforge-3d .
docker run --rm -p 8080:80 roadforge-3d
```

Откройте http://localhost:8080. Образ на этапе сборки запускает модульные тесты и production build.

## Проверено

На базовой ветке документированы 11 тестов ядра, TypeScript и production-сборка, браузерный сценарий на полном `example.osm`: изменение полос с проверкой ширины mesh, рисование, перенос вершины, светофор, удаление, Undo/Redo, экспорт и повторный импорт. Подробности и границы готовности — в [HANDOFF](docs/HANDOFF.md).
